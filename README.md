# Budget CLI
## Выполнил: Вдовиченко Даниил
Консольное приложение для управления личными финансами на TypeScript с интерактивным интерфейсом на библиотеке inquirer.

## Возможности

- просмотр списка счетов;
- создание счёта с уникальным ID;
- просмотр счёта (список транзакций и баланс);
- добавление транзакции с валидацией ввода (сумма, категория, дата);
- удаление транзакции с подтверждением;
- удаление счёта с подтверждением и удалением всех его транзакций;
- экспорт данных счёта в CSV-файл (папка `exports`, имя файла вводится пользователем);
- при запуске создаются два демонстрационных счёта с транзакциями (см. `setInitialState` в `src/index.ts`).

## Требования

- Node.js 18 или новее
- npm

## Установка

```bash
npm install
```

## Запуск

```bash
npm start
```

Навигация по меню: стрелки вверх и вниз, выбор клавишей Enter.

## Структура проекта

```
src/
  enums.ts                 перечисления (тип транзакции, пункты меню)
  interfaces.ts            интерфейсы и типы (IAccount, ITransaction и др.)
  Transaction.ts           класс транзакции
  Account.ts               класс счёта
  AccountManager.ts        управление счетами, экспорт в CSV
  ApplicationController.ts меню и ввод пользователя (inquirer)
  index.ts                 точка входа
```

## Формат даты и суммы

- дата вводится в формате `ГГГГ-ММ-ДД`, например `2026-10-21`;
- сумма: положительное число, не более двух знаков после запятой.
